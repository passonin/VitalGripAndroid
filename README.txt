Vital Grip Standalone PWA

1. Upload all files/folders in this package to an HTTPS web server.
2. Open the site from Safari (iPhone) or Chrome (Android).
3. iPhone: Share -> Add to Home Screen.
4. Android: Chrome menu -> Install app / Add to Home screen.
5. Launch Vital Grip from the home-screen icon. It will use standalone app
   display without the normal browser address bar.

Important:
- The app is PWA/standalone capable.
- Android Chrome supports Web Bluetooth in supported configurations.
- iPhone/iOS Safari does not provide Web Bluetooth API support, so the
  existing Bluno Bluetooth button cannot connect to Bluno from iPhone.
  The visual/app-shell behavior still works on iPhone.
